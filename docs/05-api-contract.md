# 05 — REST API Contract

Every route is exposed through the gateway on `http://localhost:8080`. Services are never called directly by
the frontend.

## 0. Conventions

**Versioning** — all paths are prefixed with `/api/v1`. A breaking change means `/api/v2`, served in parallel.

**Gateway routing**

| Path predicate | Target service | Requires a token at the edge |
|---|---|---|
| `/api/v1/auth/**` | `auth-service` | No (public: login, register, refresh) |
| `/api/v1/users/**` | `auth-service` | Yes |
| `/api/v1/products/**`, `/api/v1/categories/**` | `catalog-service` | Only for write methods |
| `/api/v1/warehouses/**`, `/api/v1/stock/**`, `/api/v1/inventory/**` | `inventory-service` | Yes |
| `/api/v1/orders/**` | `order-service` | Yes |

**Authentication** — `Authorization: Bearer <accessToken>` on every non-public route.

JWT claims:

```json
{
  "iss": "logistics-auth",
  "sub": "3f9a...-b21c",
  "email": "user@example.com",
  "roles": ["ROLE_CLIENT"],
  "iat": 1772000000,
  "exp": 1772000900,
  "jti": "0a1b...-9cd2"
}
```

**Standard headers**

| Header | Direction | Purpose |
|---|---|---|
| `X-Request-Id` | in/out | Correlation id; generated by the gateway when absent, echoed in every response |
| `Idempotency-Key` | in | Required on `POST /orders` and `POST /inventory/reservations` |
| `Location` | out | Returned with every `201` |

**Error format — RFC 7807 (`application/problem+json`)**

```json
{
  "type": "https://logistics.local/problems/allocation-failed",
  "title": "Allocation failed",
  "status": 409,
  "detail": "No combination of warehouses can fulfil this order.",
  "instance": "/api/v1/orders",
  "timestamp": "2026-09-03T10:15:30Z",
  "requestId": "c0ffee-1234",
  "errors": [
    { "field": "lines[0].quantity", "message": "must be greater than 0" }
  ]
}
```

`errors` is present only for validation problems.

**Status codes used platform-wide**

| Code | Meaning in this platform |
|---|---|
| `200` | Read or update succeeded |
| `201` | Resource created (`Location` header set) |
| `204` | Deleted / logged out, no body |
| `400` | Malformed body or Bean Validation failure |
| `401` | Missing, expired or invalid token |
| `403` | Valid token, insufficient role or not the owner of the resource |
| `404` | Resource not found (or hidden from a non-owner) |
| `409` | Conflict: duplicate key, illegal state transition, insufficient stock, allocation impossible |
| `422` | Semantically invalid: unknown or discontinued product |
| `503` | A downstream service is unavailable |

**Pagination** — query parameters `page` (0-based), `size` (default 20, max 100), `sort` (`field,asc|desc`).
Explicit response envelope:

```json
{
  "content": [],
  "page": 0, "size": 20, "totalElements": 137, "totalPages": 7,
  "first": true, "last": false
}
```

### Payloads

```jsonc
// RegisterRequest — @NotBlank @Email; password @Size(min=10) + one digit + one uppercase
{ "email": "aya@example.com", "password": "Str0ngPass!", "firstName": "Aya", "lastName": "Bennani" }

// LoginRequest
{ "email": "aya@example.com", "password": "Str0ngPass!" }

// TokenResponse
{ "accessToken": "eyJhbGciOi...", "refreshToken": "b7f2...c91", "tokenType": "Bearer", "expiresIn": 900 }

// UserResponse — never contains passwordHash
{ "id": "3f9a...", "email": "aya@example.com", "firstName": "Aya", "lastName": "Bennani",
  "enabled": true, "roles": ["ROLE_CLIENT"], "createdAt": "2026-03-01T09:00:00Z" }

// UpdateRolesRequest — @NotEmpty, values validated against the roles table
{ "roles": ["ROLE_CLIENT", "ROLE_WAREHOUSE_MANAGER"] }
```

Rules: `register` always grants `ROLE_CLIENT` — a role can never be self-assigned. `login` returns the same
`401` message for an unknown email and a wrong password (no user enumeration). `refresh` rotates the token:
the old one is revoked in the same transaction.

### Payloads

```jsonc
// CreateProductRequest
{ "sku": "PAL-TRK-2500", "name": "Pallet truck 2500 kg", "description": "Manual pallet truck.",
  "brand": "Logimove", "categoryId": "c1a4...", "price": { "amount": 349.90, "currency": "EUR" },
  "attributes": { "capacityKg": "2500", "forkLengthMm": "1150" },
  "dimensions": { "lengthMm": 1550, "widthMm": 685, "heightMm": 1230, "weightG": 78000 },
  "images": ["https://cdn.example/pal-trk-2500.jpg"] }

// ProductBatchRequest — used by order-service, @NotEmpty @Size(max=100)
{ "productIds": ["8f2b...", "1d7c..."] }

// ProductSnapshotResponse — deliberately minimal: exactly what an order line needs
[ { "id": "8f2b...", "sku": "PAL-TRK-2500", "name": "Pallet truck 2500 kg",
    "price": { "amount": 349.90, "currency": "EUR" }, "status": "ACTIVE" } ]

// CategoryResponse (?tree=true nests children)
{ "id": "c1a4...", "name": "Pallet trucks", "slug": "pallet-trucks", "parentId": "b70f...",
  "path": "handling/pallet-trucks",
  "attributeSchema": [ { "key": "capacityKg", "label": "Capacity (kg)", "type": "NUMBER", "required": true } ],
  "children": [] }
```

Rules: `attributes` are validated against the category `attributeSchema`; a missing required attribute or an
unknown key yields `422`. `DELETE /products/{id}` is a **soft delete** (`status = DISCONTINUED`) so existing
orders keep a resolvable reference. `DELETE /categories/{id}` returns `409` when the category still has
children or products.

### Payloads

```jsonc
// CreateWarehouseRequest — latitude/longitude @NotNull and range-checked
{ "code": "WH-CASA-01", "name": "Casablanca hub",
  "address": { "line1": "Zone industrielle Sidi Bernoussi", "city": "Casablanca",
               "postalCode": "20600", "country": "MA" },
  "latitude": 33.573100, "longitude": -7.589800 }

// WarehouseResponse
{ "id": "a11e...", "code": "WH-CASA-01", "name": "Casablanca hub", "address": { }, 
  "latitude": 33.573100, "longitude": -7.589800, "active": true, "distinctProducts": 42 }

// UpsertStockItemRequest — sets an absolute level (used for initial loading / stock count)
{ "warehouseId": "a11e...", "productId": "8f2b...", "quantityOnHand": 120, "reorderThreshold": 20 }

// StockItemResponse — availableQuantity is derived, never stored
{ "id": "77aa...", "warehouseId": "a11e...", "warehouseCode": "WH-CASA-01", "productId": "8f2b...",
  "quantityOnHand": 120, "quantityReserved": 14, "availableQuantity": 106,
  "reorderThreshold": 20, "lowStock": false, "updatedAt": "2026-09-01T11:02:00Z" }

// CreateStockMovementRequest — relative adjustment; type in {INBOUND, OUTBOUND, ADJUSTMENT}
{ "warehouseId": "a11e...", "productId": "8f2b...", "type": "INBOUND",
  "quantity": 50, "reference": "DN-2026-0912" }

// AvailabilityRequest
{ "productIds": ["8f2b...", "1d7c..."] }

// AvailabilityResponse — stock AND coordinates in one call, so the allocation engine needs no second round trip
{ "warehouses": [
    { "warehouseId": "a11e...", "code": "WH-CASA-01", "latitude": 33.5731, "longitude": -7.5898,
      "availability": { "8f2b...": 6, "1d7c...": 10 } },
    { "warehouseId": "b22f...", "code": "WH-RABA-01", "latitude": 34.0209, "longitude": -6.8416,
      "availability": { "8f2b...": 12, "1d7c...": 9 } } ] }

// CreateReservationRequest — `reference` is the idempotency key (unique constraint)
{ "reference": "ORD-2026-000123", "ttlSeconds": 300,
  "segments": [ { "warehouseId": "b22f...",
                  "lines": [ { "productId": "8f2b...", "quantity": 10 },
                             { "productId": "1d7c...", "quantity": 4 } ] } ] }

// ReservationResponse
{ "id": "9c3d...", "reference": "ORD-2026-000123", "status": "ACTIVE",
  "expiresAt": "2026-09-03T10:20:30Z",
  "segments": [ { "warehouseId": "b22f...", "lines": [ { "productId": "8f2b...", "quantity": 10 } ] } ] }

// 409 on insufficient stock — says precisely what is missing
{ "type": "https://logistics.local/problems/insufficient-stock", "title": "Insufficient stock",
  "status": 409, "detail": "Stock changed since the availability snapshot.",
  "shortages": [ { "warehouseId": "b22f...", "productId": "8f2b...", "requested": 10, "available": 7 } ] }
```

Rules: replaying `POST /reservations` with the same `reference` returns the **existing** reservation with
`200` instead of creating a second one. `confirm` and `cancel` are only legal from `ACTIVE`; anything else
returns `409` with the current status. An `EXPIRED` reservation can no longer be confirmed.

### Payloads

```jsonc
// CreateOrderRequest — @Valid; `strategy` optional, falls back to the configured default
{ "lines": [ { "productId": "8f2b...", "quantity": 10 },
             { "productId": "1d7c...", "quantity": 4 } ],
  "deliveryAddress": { "line1": "12 rue des Oliviers", "city": "Casablanca",
                       "postalCode": "20250", "country": "MA",
                       "latitude": 33.589900, "longitude": -7.603900 },
  "strategy": "nearest" }
```

Validation: `lines` `@NotEmpty` `@Size(max=50)`, `quantity` `@Min(1)` `@Max(1000)`, `productId`
`@NotBlank`, no duplicate `productId`, latitude/longitude `@NotNull` and range-checked, `country` ISO-3166-2
letters. **`customerId` is deliberately absent from the payload** — it is read from the JWT.

```jsonc
// OrderResponse — 201, Location: /api/v1/orders/{id}
{ "id": "5b1c...", "orderNumber": "ORD-2026-000123", "status": "CONFIRMED",
  "customerId": "3f9a...", "createdAt": "2026-09-03T10:15:30Z",
  "total": { "amount": 3859.60, "currency": "EUR" },
  "deliveryAddress": { "line1": "12 rue des Oliviers", "city": "Casablanca",
                       "postalCode": "20250", "country": "MA",
                       "latitude": 33.5899, "longitude": -7.6039 },
  "allocationStrategy": "nearest", "splitShipment": false,
  "lines": [ { "id": "aa01...", "productId": "8f2b...", "sku": "PAL-TRK-2500",
               "name": "Pallet truck 2500 kg", "quantity": 10,
               "unitPrice": { "amount": 349.90, "currency": "EUR" },
               "lineTotal": { "amount": 3499.00, "currency": "EUR" } } ],
  "allocations": [ { "warehouseId": "b22f...", "warehouseCode": "WH-RABA-01",
                     "shipmentSequence": 1, "distanceKm": 87.24,
                     "lines": [ { "orderLineId": "aa01...", "productId": "8f2b...", "quantity": 10 } ] } ] }

// 409 when allocation is impossible — the order exists in REJECTED state and is returned
{ "type": "https://logistics.local/problems/allocation-failed", "title": "Allocation failed",
  "status": 409, "detail": "No combination of warehouses can fulfil this order.",
  "orderNumber": "ORD-2026-000126",
  "unsatisfiedLines": [ { "productId": "8f2b...", "requested": 10, "availableAcrossNetwork": 6 } ] }

// 422 when a product is unknown or discontinued
{ "type": "https://logistics.local/problems/product-unavailable", "title": "Product unavailable",
  "status": 422, "detail": "Some products are unknown or discontinued.",
  "unavailableProducts": [ { "productId": "1d7c...", "reason": "DISCONTINUED" } ] }

// UpdateOrderStatusRequest — only SHIPPED and DELIVERED are accepted here
{ "status": "SHIPPED", "reason": "Handed over to the carrier" }

// AllocationPreviewRequest — runs the engine WITHOUT persisting anything.
// Demo value: compare both strategies on the same order.
{ "lines": [ { "productId": "8f2b...", "quantity": 10 } ],
  "destination": { "latitude": 33.5899, "longitude": -7.6039 },
  "strategies": ["nearest", "single-shipment"] }

// AllocationPreviewResponse
{ "results": [
    { "strategy": "nearest", "feasible": true, "splitShipment": false,
      "segments": [ { "warehouseCode": "WH-RABA-01", "distanceKm": 87.24,
                      "lines": [ { "productId": "8f2b...", "quantity": 10 } ] } ] },
    { "strategy": "single-shipment", "feasible": true, "splitShipment": false,
      "segments": [ { "warehouseCode": "WH-TANG-01", "distanceKm": 340.12,
                      "lines": [ { "productId": "8f2b...", "quantity": 10 } ] } ] } ] }
```

> `POST /orders/allocation-preview` exists for a reason beyond convenience: it makes the business rule
> **observable in the UI**. Being able to show, live, that two strategies produce two different plans on the
> same order is the strongest possible demonstration of the Strategy pattern in an interview.
